> **注意**：本文数字产生于逐 token 读出与 α 钳制之前。范数比只取决于状态转移、与读出无关，结论仍有效；但代码版本已变，E6 将在 v1 门禁后按主配置重跑一次，届时以新 JSON 为准。

**日期**：2026-10-30
**脚本**：`code/e6_stability.py`；记录：`results/e6_stability.json`
**对象**：未训练的 bi-SRNL（默认 γ=0.025、α_init=0.95、C=16、2 层×双向），以及 γ=5 对照；真实 FD001 验证集窗口 8 条、L=30。
**说明**：范数比指相邻状态 ‖S_new‖/‖S_old‖ 的最大值；chunk=16 时只在块边界可测，chunk=1 即逐 token。

## 1 结果

| 检查 | finite | max 范数比 | 末态范数 |
|---|---|---|---|
| bi-SRNL 默认 γ=0.025 | True | 0.480308 | 1.229e-01 |
| B8 定规则 SRNL 默认 | True | 0.478707 | 1.260e-01 |
| γ=5 有控制 | True | 0.476148 | 1.177e-01 |
| γ=5 **无控制**（对照，不作要求） | True | 6.15e+08 | 5.249e+13 |
| 逐 token（chunk=1） | True | 0.949158 | 2.675e-01 |

抽样转移算子：max‖A‖₂ = 0.950000，max‖B‖₂ = 0.015176（2 条序列 × 4 头，第 1 个 token）。

**判定：PASS**（除 γ=5 无控制外，全部 finite 且范数比 ≤1）。

## 2 解读

- 默认设置下，块边界范数比 ≤1，与探针结论一致；逐 token 的 0.949 也 ≤1。
- γ=5 时，去掉软上限/谱钳制后范数比达 6×10⁸、末态范数 5×10¹³；加上控制后回到 0.476。**这支持“控制项是必要的”而非“默认参数会 NaN”**：L=30 时无控制仍有限，只是数值爆炸；01 N-C 的“默认 γ 可能有限”成立。
- 训练后的 E1 模型范数比 0.999308（`results/e1_smoke.json`），仍 ≤1；说明学习到的 η/α 会把系统推到接近但不超过边界。
- 未训练模型的 0.48 主要因为 M0 初值小、零行多，不代表训练后的行为；训练后数值才是主证据。

## 3 边界

- 只在 FD001、L=30、8 条窗口上做；未覆盖 FD002/FD004 与全部 5 种子。
- 未做 ‖A‖₂ 的逐 token 全量统计（只抽样 8 个头×1 步）；正式图 2 需在 E3/E6 补全。
- γ=5 无控制在更长序列（L=512）会出现 inf/NaN（探针已见）；本文 L=30 只报“数值爆炸”，不写 NaN。
