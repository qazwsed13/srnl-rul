# E4 机理证据：α/η 随退化阶段变化（5 种子 × FD002/FD004）

**日期**：2026-10-31
**脚本**：`code/collect_mechanism.py`（采集）、`code/summarize_mechanism.py`（汇总）
**数据**：`results/mechanism_<FD>_gate_s<0-4>.csv/json`、`results/mechanism_summary.json`
**模型**：E2b 最终 checkpoint（stem + C16，5 种子）；**gate split**（39/38 台发动机，3 截断/台），**未用 test**。
**统计**：`encoder.layers.0.fwd`，对 4 头与窗口内 token 取均值；每种子独立，表中为 5 种子均值 ± sd。

## 2 按工况（窗口末时刻 k-means 簇）

- FD002：六工况 α 极差 0.0019、η 极差 0.0005。
- FD004：α 极差 0.0017、η 极差 0.0003。
- 结论：工况归一化后，自指步长几乎不随工况变化；变化由**退化阶段**驱动，不是工况标签。

## 3 解读

- 越接近失效，模型**提高保留率 α、减小步长 η**：记忆更稳、写入更保守；早期相反。两个多工况子集、5 个种子方向一致、幅度接近。
- 这解释了定规则 B8（α/η 输入无关）为何在 test 上四个子集都更差（FD002 显著，Holm p=0.0068）：固定步长无法在临近失效时收紧写入。
- 与稳定性控制配合：α→1 时软上限把 η 压得更小，形成“临近失效的平滑死区”；这也是 α 钳制（1−1e−6）必须存在的数值原因。
- 论文定位：机理证据（图 4），不是精度主张；主表仍是 RMSE/Score。

## 4 边界

- 只看第 1 层前向扫描；第 2 层/反向的分布待补充图（可放补充材料）。
- 工况标签来自训练集 k-means(k=6)，不是真实工况元数据；只用于分层描述。
- 相关是描述性的，不构成因果；跨子集一致性与 B8 对照共同支撑“自指有用”。
- gate split 是训练发动机的留出集；test 未参与。
