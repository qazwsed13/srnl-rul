# 现阶段指标诊断（2026-10-30）

**用途**：在 E2b test 结果出来前，判断现有 gate/val 指标的可靠性、测试集可能的表现与可辩护的主张。所有数字来自 `results/` 的逐发动机预测；脚本 `code/diagnose_metrics.py`、`code/calibration_check.py`。

## 1 标签分布：test 比 gate 更靠晚段

| 集合 | n | 均值 | 中位 | p10 | p90 | >125 |
|---|---|---|---|---|---|---|
| FD002 test | 259 | 81.2 | 80.0 | 11.0 | 158.6 | 57 |
| FD002 gate（3×39） | 117 | 76.0 | 78.0 | 17.0 | 125.0 | 0 |
| FD004 test | 248 | 86.6 | 88.0 | 13.0 | 163.6 | 67 |
| FD004 gate（3×38） | 114 | 89.1 | 107.5 | 18.8 | 125.0 | 0 |

- gate 的截断点均匀分布在发动机全寿命，**中位 RUL 偏高**（FD004 107.5 vs test 88），因此 gate RMSE 偏乐观；test 更靠晚段，而模型在晚段系统性高估，test RMSE 大概率高于 gate。
- FD002 的 gate 与 test 中位接近（78 vs 80），外推风险较小。

- 中位绝对误差只有 4.5–8.1 周期，聚合 RMSE 的 45–59% 来自前 5 台发动机（FD004 反复是 185、78、242）。

- **含义**：主表仍报聚合 RMSE（领域惯例），但必须同时报逐发动机配对统计与中位 AE，避免“一台坏发动机决定结论”。

## 4 验证集偏差校准（不碰 test）

用 val_trunc 的均值偏差校正 gate 预测（每个模型、每个种子各自拟合）：

|---|---|---|---|

| FD002 TCN | 15.10 | 14.79 | −2.04% |
| FD004 本文 | 12.21 | 12.13 | −0.67% |

- 校准对双方都有 1–3.5% 的改善，但不改变“FD002 接近、FD004 本文略优”的格局；本文 FD002 的差距从 +2.5% 收到约 +2.1%。
- **决定**：主表保持**未校准**的标准口径；校准作为补充分析/讨论，不进主表、不改变主张。理由是 test RUL 分布与 val 不同，校准的迁移性只在 gate 上验证过。

## 5 对 test 结果的预期与主张边界

- FD002：test 中位 RUL 与 gate 接近，预计本文与 TCN 的差距在 ±2% 内，配对 CI 可能含 0 → 故事 B 的“可比”可成立。
- FD004：test 更靠晚段，所有模型 RMSE 都会上升；本文 gate 领先 4.2%，但晚段偏差与 TCN 接近，test 可能收敛到 ±2% 内。
- **故事 A（显著优于 B5 ≥1% 且 CI 下限>0）概率低**；**故事 B（可比 + 有界 + 机理）是主路径**。
- 主表口径：RMSE（cap125）为主、raw 为补充；Score 同时报但注明系数口径；逐发动机 Wilcoxon + Holm + bootstrap 必报；中位 AE 与晚段偏差作为机理/讨论证据。
- 若 test 上本文在两个子集都显著更差（CI 不含 0 且 Δ>1%），按 01 §3.3 负结果纪律处理，不再调参洗结果。
